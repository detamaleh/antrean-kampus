# Panduan Kontribusi Tim

## Strategi Branching
Tim menggunakan GitHub Flow.

## Aturan Branch
1. Setiap anggota bekerja pada branch masing-masing.
2. Nama branch menggunakan format tipe/deskripsi.
3. Contoh: docs/profil-mahasiswa1.
4. Jangan melakukan perubahan langsung pada main.

## Konvensi Commit
Gunakan format Conventional Commits.

Contoh:
- docs: tambah profil mahasiswa
- docs(anggota): lengkapi profil mahasiswa
- feat: tambah fitur aplikasi
- fix: perbaiki kesalahan aplikasi

## Aturan Kolaborasi
1. Setiap anggota menggunakan akun GitHub sendiri.
2. Setiap perubahan dibuat di branch pribadi.
3. Perubahan ke main dilakukan melalui Pull Request.
4. Pull Request memerlukan satu persetujuan sebelum digabungkan.
5. Dilarang menyimpan password, token, atau SSH Private Key.
